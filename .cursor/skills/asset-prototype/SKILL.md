# Workflow
1. Check if local machine has this `git@github.com:nex-team-inc/music-cell-shared-assets.git` repo in `Documents` folder.
2. If not, prompt user to clone this repo, or tell user to specify where this repo is.
3. Read [references/music-cell-shared-assets.md](references/music-cell-shared-assets.md) to identify the most relevant asset category.
4. Browse the repo based on the keywords provided by the user, and find the most suitable match.
5. Inspect the candidate asset and its dependencies before copying or exporting it into the current project.
