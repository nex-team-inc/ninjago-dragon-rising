# Asset reference index

Start here when looking for prototype assets. Search by the asset's role first, then open the
linked source catalog for the complete inventory, licensing information, and download page.

The source catalogs remain authoritative. This file is a routing index and intentionally does not
duplicate their full asset lists.

## Search workflow

1. Choose the closest type and theme above.
2. Open the linked source catalog and search its complete inventory with the user's keywords.
3. Prefer a source catalog's direct asset entry over a broad external search.
4. Inspect dependencies and verify the license before importing anything into Unity.

All external entries in this index are intended to be free assets. Do not select paid bundles,
paid tiers, or paid source/engine integrations.
